# 🏃 Petit Garçon Runner (ancien projet, conservé)

Jeu arcade pygame : ESPACE pour sauter, R pour recommencer. Évitez les arbres, ramassez pièces, billets et donuts.
Lancement : `pip install pygame` puis `python "garcon runner source.py"` (ou double-clic sur `garcon runner.exe`).
